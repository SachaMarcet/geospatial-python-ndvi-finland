# NDVI Finland Project

Python-based NDVI analysis of Sentinel-2 imagery over Finland.

## Overview
This project calculates the Normalized Difference Vegetation Index (NDVI) from Sentinel-2 satellite data to assess vegetation health.

## Status
Work in progress – initial repository setup and structure.

## Planned Features
- NDVI calculation from Red and NIR bands
- Visualization of NDVI maps
- Basic statistical analysis
- Support for Finnish Sentinel-2 tiles

## Tools
- Python
- numpy
- rasterio
- matplotlib
